# A-amos算法设计说明

## 一、算法概述

A-amos（Adaptive Multi-objective Optimization for Order Assignment）是基于PRMO算法改造的订单分配多目标优化算法，专门用于求解`planner_order_v3`问题。

### 1.1 问题特性

- **决策变量类型**：离散序列（点编号1-20 + 0分隔符）
- **编码方式**：排列编码（encoding=5）
- **约束类型**：顺序约束（商家必须在对应客户点之前访问）
- **目标函数**：能耗最小化、时间成本最小化

### 1.2 与PRMO的主要区别

| 维度 | PRMO原始算法 | A-amos算法 |
|------|------------|-----------|
| 决策变量 | 连续值（3D坐标） | 离散序列（点编号） |
| 聚类空间 | 决策空间（坐标空间） | **目标空间（能耗-时间空间）** |
| 约束处理 | 空间碰撞检测 | 顺序约束修复 |
| 交叉操作 | 差分进化交叉 | **基于段的离散交叉** |
| 变异操作 | 多项式变异 | **离散序列变异** |
| 修复机制 | 空间引导修复 | **顺序约束修复** |

## 二、核心设计原理

### 2.1 目标空间聚类

#### 为什么使用目标空间聚类？

**原理1：离散序列的决策空间距离缺乏语义**

对于离散序列优化问题，决策空间（序列编号）的欧氏距离无法反映解的相似性。例如：
- 解A: [1, 2, 3, 0, 4, 5, 6, 0, 7, 8, 9, 10]
- 解B: [10, 9, 8, 0, 7, 6, 5, 0, 4, 3, 2, 1]

这两个解在决策空间的欧氏距离很大，但目标值可能相近。

**原理2：多目标优化的Pareto支配关系在目标空间**

- Pareto最优解集在目标空间形成前沿
- 支配关系、收敛性、多样性都在目标空间定义
- 目标空间聚类能直接反映解的优劣与分布

**原理3：邻域搜索的有效性**

- 目标值相近的解聚在一起
- 从目标空间邻域选择父代，更可能产生目标值相近的子代
- 局部搜索更有效

#### 实现方式

```matlab
% 在目标空间计算聚类中心
centroid = mean(objVals(clustTag==clustName(i), :), 1);  % 目标空间均值

% 基于目标空间距离合并聚类
distances = pdist(centroid);  % 目标空间距离
```

### 2.2 基于段的离散交叉

#### 设计思路

保留0分隔符结构，在段级别进行交叉，确保：
- 保持无人机路径段的完整性
- 避免破坏解的结构
- 修复重复和缺失的点

#### 实现策略

1. **段级交叉**：随机选择要交换的段
2. **结构保持**：保持0分隔符位置
3. **修复机制**：修复重复和缺失的点

```matlab
% 随机选择要交换的段
numSegsToSwap = randi([1, m-1]);
segsToSwap = randperm(m, numSegsToSwap);

% 从不同父代取段
for k = 1:m
    if ismember(k, segsToSwap)
        offspring = [offspring segments2{k}];
    else
        offspring = [offspring segments1{k}];
    end
end
```

### 2.3 离散序列变异

#### 四种变异策略

1. **交换变异（Swap）**：随机选择两个非0位置交换
2. **插入变异（Insert）**：随机选择一个点，插入到新位置
3. **段内重排（Segment Reorder）**：在保持0分隔符的前提下，重排某段内的点
4. **段间移动（Segment Move）**：将某个点从一个段移动到另一个段

#### 随机选择策略

```matlab
mutationType = randi(4);  % 随机选择变异类型
switch mutationType
    case 1: offspring = SwapMutation(individual);
    case 2: offspring = InsertMutation(individual);
    case 3: offspring = SegmentReorderMutation(individual, m);
    case 4: offspring = SegmentMoveMutation(individual, m);
end
```

### 2.4 顺序约束修复

#### 约束规则

商家i必须在客户点(i+n)之前访问，其中：
- 商家编号：1-10
- 客户点编号：11-20
- n = 10（客户点数量）

#### 修复策略

1. **段内修复**：如果商家和客户点在同一段，检查顺序并交换
2. **段间修复**：如果商家段在客户点段之后，将商家移动到客户点所在段

```matlab
% 如果商家在客户点之后，交换位置
if merchant_pos_in_seg >= customer_pos_in_seg
    % 交换位置
    temp = segVals(merchant_pos_in_seg);
    segVals(merchant_pos_in_seg) = segVals(customer_pos_in_seg);
    segVals(customer_pos_in_seg) = temp;
end
```

## 三、算法流程

```
初始化种群 → 评估目标函数
    ↓
主循环开始
    ↓
目标空间聚类 → 确定邻域集合
    ↓
对每个个体：
  - 选择父代（邻域/全局，自适应概率）
  - 顺序约束修复（如有违反）
  - 基于段的离散交叉
  - 离散序列变异
  - 再次顺序约束修复
    ↓
环境选择（非支配排序 + 超体积指标）
    ↓
更新聚类信息（目标空间） → 下一代
    ↓
直到满足终止条件
```

## 四、关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| Kmax | 8 | 目标空间聚类最大数量 |
| BETA | 0.8 | 邻域选择平衡参数（早期全局搜索，后期局部搜索） |
| pc | 0.8 | 交叉概率 |
| pm | 0.1 | 变异概率 |
| maxgen | 300 | 最大迭代次数 |

### 参数调整建议

- **Kmax**：目标空间聚类数，建议5-10，根据问题规模调整
- **BETA**：控制全局/局部搜索平衡，建议0.5-1.0
- **pc/pm**：交叉和变异概率，可根据收敛情况调整

## 五、环境选择机制

### 5.1 非支配排序

使用NDSort进行非支配排序，将解分为多个非支配层。

### 5.2 超体积指标

- **2目标问题**：使用精确的超体积计算
- **多目标问题**：使用简化的超体积计算

### 5.3 选择策略

1. 按非支配层选择
2. 如果超过选择数量，使用超体积贡献删除多余解

## 六、算法优势

1. **适配离散序列**：专门针对离散序列优化设计
2. **目标空间导向**：聚类和搜索在目标空间进行，更符合多目标优化理论
3. **约束处理**：主动修复顺序约束，提高解的可行性
4. **多样性保持**：多种变异策略保持解的多样性
5. **自适应搜索**：根据迭代次数自适应调整全局/局部搜索比例

## 七、与PRMO的对比总结

### 7.1 核心改进

1. **聚类空间**：决策空间 → 目标空间
2. **进化操作**：连续操作 → 离散操作
3. **约束处理**：碰撞检测 → 顺序约束修复
4. **修复机制**：空间引导 → 顺序修复

### 7.2 理论依据

- **离散序列的相似性应基于目标值，而非序列本身**
- **目标空间聚类能更好地识别有意义的解群**
- **邻域应基于解的"质量相似性"，而非"结构相似性"**

## 八、使用说明

### 8.1 调用方式

```matlab
Algorithm = A_amos('parameter', [8, 0.8, 0.8, 0.1, 300]);
Problem = planner_order_v3('N', 100, 'M', 2);
Algorithm.Solve(Problem);
```

### 8.2 参数设置

```matlab
[Kmax, BETA, pc, pm, maxgen] = Algorithm.ParameterSet(8, 0.8, 0.8, 0.1, 300);
```
