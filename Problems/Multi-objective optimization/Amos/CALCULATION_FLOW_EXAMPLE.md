# 计算流程示例和错误检查

## 示例解

假设有一个解：`route = [1, 11, 2, 12, 0, 3, 13, 4, 14, 0, 5, 15, 6, 16, 7, 17, 8, 18, 9, 19, 10, 20]`

**参数设置：**
- n = 10（10个商家，10个客户点）
- m = 3（3架无人机）
- D = 22（2*n + (m-1) = 20 + 2 = 22）
- demand_q = [0.5; 0.7; 0.65; 0.9; 0.35; 0.2; 0.9; 0.1; 0.45; 0.77]

**路径分段：**
- 无人机1：`seg1 = [1, 11, 2, 12]` → depot → 商家1 → 客户点11 → 商家2 → 客户点12 → depot
- 无人机2：`seg2 = [3, 13, 4, 14]` → depot → 商家3 → 客户点13 → 商家4 → 客户点14 → depot
- 无人机3：`seg3 = [5, 15, 6, 16, 7, 17, 8, 18, 9, 19, 10, 20]` → depot → 商家5 → 客户点15 → ... → 商家10 → 客户点20 → depot

## 步骤1：载重计算（修复后）

### 无人机1：seg1 = [1, 11, 2, 12]

**代码：** `segforlength = [0, seg, 0] = [0, 1, 11, 2, 12, 0]`

**载重计算循环（修复后）：**
```
load_at_point(1) = 0.0  % depot出发时载重为0

i=2: point_id=1 (商家1)
  - customer_idx = 1
  - load_at_point(2) = 0.0 + demand_q(1) = 0.0 + 0.5 = 0.5
  - 到达商家1后载重 = 0.5

i=3: point_id=11 (客户点11)
  - customer_idx = 11 - 10 = 1
  - load_at_point(3) = 0.5 - demand_q(1) = 0.5 - 0.5 = 0.0
  - 到达客户点11后载重 = 0.0

i=4: point_id=2 (商家2)
  - customer_idx = 2
  - load_at_point(4) = 0.0 + demand_q(2) = 0.0 + 0.7 = 0.7
  - 到达商家2后载重 = 0.7

i=5: point_id=12 (客户点12)
  - customer_idx = 12 - 10 = 2
  - load_at_point(5) = 0.7 - demand_q(2) = 0.7 - 0.7 = 0.0
  - 到达客户点12后载重 = 0.0

load_at_point(6) = 0.0  % 回到depot时载重为0
```

**结果：** 
- `load_at_point = [0.0, 0.5, 0.0, 0.7, 0.0, 0.0]`
- `load_kg = load_at_point(1:end-1) = [0.0, 0.5, 0.0, 0.7, 0.0]` ✓
- `load_all(1) = max(load_at_point) = 0.7` ✓

**说明：** `load_kg(i)` 现在正确表示从 `segforlength(i)` 起飞时的载重

## ✅ 已修复的错误

### 错误1：载重索引不匹配（已修复）

**问题位置：** `planner_order_v3.m:394-473`

**问题描述：**
- 原代码使用 `segforload = [seg, 2*n+1]` 计算载重，但 `segforlength = [0, seg, 0]` 用于能量计算
- 索引不匹配导致使用了错误的载重值

**修复方案：**
- 现在使用 `segforlength` 统一计算载重
- `load_at_point(i)` 表示到达 `segforlength(i)` 后的载重
- `load_kg(i) = load_at_point(i)` 表示从 `segforlength(i)` 起飞时的载重
